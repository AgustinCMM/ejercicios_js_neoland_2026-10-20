Ejercicio 10 · Condiciones redundantes

Consigna

Condiciones Redundantes: El código funciona, pero no es la forma en la que un profesional lo escribiría. ¿Cómo reescribirías esto para que sea directo y limpio? 

let esAdmin = true;
if (esAdmin == true) { print("Panel principal"); }

Condiciones redundantes

Respuesta:
La forma de escribirlo sería sin la comparación == true, ya que una variable booleana, hace eso por defecto. Entonces quedaría así:

let esAdmin = true;
if (esAdmin) { console.log("Panel principal"); }
