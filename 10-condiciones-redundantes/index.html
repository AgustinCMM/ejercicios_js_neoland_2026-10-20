Consigna

El código funciona, pero no es la forma en la que un profesional lo escribiría. ¿Cómo reescribirías esto para que sea directo y limpio?

Preguntas para responder

  • ¿Qué devuelve la comparación esAdmin == true si esAdmin ya es un booleano?
  • ¿Cómo se puede escribir la condición de forma directa?
  • ¿Cambia el comportamiento del programa con tu versión?

Código a analizar

if (esAdmin == true) {
    console.log("Panel principal");
}

Nota: en el navegador usamos console.log() en lugar de print(), que es el que aparece en el material.
