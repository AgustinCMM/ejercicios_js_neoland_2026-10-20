Ejercicio 09 · Código inalcanzable

Lectura de código · if/else if · Flujo de ejecución

Consigna

Explicá por qué a x nunca se le asignará el valor 30, sin importar si empezamos con un 15, un 50 o un 100.

Preguntas para responder

  • ¿Qué condición se evalúa primero y cuál después?
  • ¿Puede llegar a ejecutarse la rama del else if? ¿Por qué?
  • ¿Qué valor toma x en cada uno de los tres casos?

Código a analizar

let x = 15;
if (x > 5) {
    x = 20;
} else if (x > 10) {
    x = 30;
}

Cómo probar

🖥️ Abrí este archivo en el navegador, presioná F12 y andá a la pestaña Console. El código ya está cargado en assets/js/script.js.
