Ejercicio 08 · Evaluación cortocircuito

Lectura de código · Operador AND (&&) · División por 0

Consigna

Explicá por qué el programa no se rompe matemáticamente al intentar dividir por 0 en este caso específico.

Preguntas para responder

  • ¿En qué orden se evalúan los dos operandos de &&?
  • Si el primero es false, ¿se evalúa la división? ¿Por qué?
  • ¿Qué pasaría si se invirtiera el orden de las condiciones?

Código a analizar

let divisor = 0;
if (divisor != 0 && (100 / divisor) > 5) {
    console.log("Válido");
}

Nota: en el navegador usamos console.log() en lugar de print(), que es el que aparece en el material.

Cómo probar

🖥️ Abrí este archivo en el navegador, presioná F12 y andá a la pestaña Console. El código ya está cargado en assets/js/script.js.
