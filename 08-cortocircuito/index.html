Ejercicio 08 · Evaluación cortocircuito

Consigna

Evaluación Cortocircuito: Explica por qué el programa no se rompe matemáticamente al intentar dividir por 0 en este caso específico. 

let divisor = 0;
if (divisor != 0 && (100 / divisor) > 5) { print("Válido"); }

Evaluación cortocircuito

Respuesta:
No se rompe porque no cumple la primera condición para poder ingresar al condicional ya que divisor SÍ es igual a 0. Por lo tanto, como ya no cumple la primera condición, directamente no evalúa las siguientes y sigue de largo. Entonces nunca intenta dividir por cero.
